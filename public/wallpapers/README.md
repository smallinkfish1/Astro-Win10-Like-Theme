# 自备壁纸放这里

控制面板 → 外观 → 壁纸，除了「默认（Win10 蓝）」之外的三张需要你自己放图。

## 需要补的文件

| 壁纸 | 亮色版 | 暗色版 |
|---|---|---|
| 极光 | `aurora.jpg` | `aurora-dark.jpg` |
| 山脉 | `mountains.jpg` | `mountains-dark.jpg` |
| 抽象几何 | `abstract.jpg` | `abstract-dark.jpg` |

## 说明

- **没放图也不会坏事。** 控制面板里那张卡片会显示成「＋ 待补充」并且**点不动** ——
  这是故意的：如果允许点，`data-wallpaper` 会指向一张 404 的图，
  壁纸层什么都画不出来，你会看到整个桌面变成纯色，以为把系统点坏了。

- **尺寸建议** 1920×1080 以上，横构图。文件建议压到 300KB 以内
  （壁纸是首屏最大的一张图，太大会拖慢加载）。

- **亮/暗两张的建议做法**：暗色版不用重新找图，把亮色版整体压暗、
  降一点饱和度就行。也可以直接拿同一张图用两次，能跑通，
  只是暗色模式下会显得偏亮。

- 放好之后**不用改代码**，刷新页面就能在控制面板里看到缩略图。

## 想换成自己的图 / 加新壁纸

壁纸清单在 `src/lib/wallpaper.ts` 的 `WALLPAPERS` 数组里，
加一项、把两个路径指向你的文件就行。CSS 那边不用动 ——
`global.css` 里用的是 `[data-wallpaper="你的id"]` 属性选择器。
