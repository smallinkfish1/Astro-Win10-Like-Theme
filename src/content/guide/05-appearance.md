# 如何换壁纸和改主题

这些设置都能在桌面上的**「控制面板」**里点着改，不用碰代码。需要改代码的只有「加一张属于自己的壁纸」这一件事。

## 用控制面板改（不用写代码）

双击桌面上的**控制面板**图标 → 左侧选「外观」，右边就是全部外观开关：

| 设置项 | 作用 |
| --- | --- |
| 壁纸 | 换背景图 |
| 亮色 / 暗色 | 切换整体配色 |
| 毛玻璃 | 开关窗口和任务栏的模糊效果 |
| 动画 | 开关窗口的开合动画 |
| 开始菜单配色 | 开始菜单跟随暗色还是亮色 |

点一下立即生效，**设置会记住**，下次打开还是你选的那样。

> 💡 这些设置存在浏览器本地，所以**换台电脑就要重设**。
> 想永久默认成某个值，看下面「改代码改默认值」一节。

## 加一张自己的壁纸

### 第一步：把图片放进目录

```text
public/wallpapers/
```

支持的常见格式都行（jpg / png / webp）。

> ⚠️ **仓库里默认没有附带壁纸图片**，只有一个说明用的 README。
> 所以刚克隆下来时，壁纸选择器里那些位置会显示「待补充」占位块 ——
> 这是**正常状态**，不是坏了。放进去图就有了。

### 第二步：让选择器认识它

壁纸清单在：

```text
src/lib/wallpaper.ts
```

按里面的格式把你的文件名加进去即可。

> ⚠️ 图片路径**必须以 `/` 开头**（`/wallpapers/my-bg.jpg`）。
> 这是老坑：不带开头的 `/` 在二级页面下会解析到错误的位置。

## 改代码改默认值

想改「新访客第一次打开时看到什么」，找这几个文件：

| 想改什么 | 改哪 |
| --- | --- |
| 配色（亮色/暗色的具体颜色） | `src/styles/global.css` 里的 CSS 变量 |
| 默认壁纸 | `src/lib/wallpaper.ts` |
| 默认主题（亮/暗） | 主题相关的启动默认值 |

### 关于 CSS 变量

**整个项目的颜色都走 CSS 变量**，所以改配色只需要动一个地方：

```css
/* src/styles/global.css */
:root {
  --fg: ...;             /* 正文文字 */
  --fg-dim: ...;         /* 次要文字 */
  --accent: ...;         /* 强调色（链接、按钮） */
  --surface: ...;        /* 面板底色 */
  /* ... */
}
```

> ⚠️ **不要在组件里写死颜色**（比如 `text-[#333]`）。
> 那样切到暗色模式时，这块就会变成「暗背景上的深灰字」，看不清。
> 永远用 `var(--fg)` 这种写法，亮暗模式自动跟随。
>
> 项目里现在还有少量早期写死的颜色（比如回收站和记事本里的几处），
> 属于历史遗留，属于「已知但没空改」的状态。

## 毛玻璃为什么会「没效果」

毛玻璃用的是 CSS 的 `backdrop-filter`。它对环境有要求：

1. **浏览器要支持**（现代浏览器都支持）
2. **窗口后面得有东西可模糊** —— 如果壁纸是纯色，模糊了就还是纯色，看不出区别

所以「开了毛玻璃但感觉没变化」，多半是因为当前壁纸太素。换一张有细节的图就很明显了。
